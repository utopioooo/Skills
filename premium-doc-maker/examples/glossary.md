# 术语表（样例）

维护在课程工作区（不必打进交付包）。作用是让 30 讲对同一个概念用同一个叫法。

规则：

- 同一概念只留一个中文译名，英文原名括注一次。
- 首次出现的讲次写清楚，后文直接复用。
- 代码里的标识符不受译名影响，但正文叙述必须统一。
- 发现两种叫法并存时，先改术语表，再全书替换。

| 术语 | 英文 | 统一写法 | 首次出现 | 备注 |
|---|---|---|---|---|
| 缓存行 | cache line | 缓存行（cache line） | 第 2 讲 | 不写“缓存块” |
| 伪共享 | false sharing | 伪共享（false sharing） | 第 2 讲 | 不写“假共享” |
| 移动语义 | move semantics | 移动语义 | 第 1 讲 | 不写“搬移语义” |
| 返回值优化 | RVO / NRVO | 返回值优化（RVO/NRVO） | 第 1 讲 | 首次出现给全称 |
| 无锁 | lock-free | 无锁（lock-free） | 第 3 讲 | 与“免锁”区分 |
| 内存序 | memory order | 内存序 | 第 3 讲 | 不写“内存顺序” |
| 基准测试 | benchmark | 基准测试 | 第 4 讲 | 不写“跑分” |

## 使用方式

1. 阶段 1 写大纲时先建表，把每讲要用的核心术语列进去。
2. 阶段 4 每写完一讲，回表检查：是否出现表外叫法、是否重复括注英文。
3. 交付前全书搜索一遍旧叫法，确认没有残留。
