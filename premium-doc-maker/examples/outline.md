# 课程大纲：C++高性能编程与系统开发

- 课程名：C++高性能编程与系统开发
- 副标题：深入探索现代 C++ 性能极限，构建高效可靠的软件系统。
- 品牌：翎光技术文档
- 作者：翎光技术文档
- Slogan：探索技术深度，挖掘知识价值
- 年份：2026
- 风格：blue-ink

## 第 1 讲 内存管理与性能
- 摘要：内存布局、栈与堆、自定义分配器、内存池
- 阶段：基础认知
- 能力点：能定位内存瓶颈，并选择合适的分配策略
- 前置：无
- 难度：进阶
- 时长：45

### 小节
1. 引言：内存去哪了
2. 一、栈与堆的边界
3. 二、自定义分配器
4. 三、方案对比与选型
5. 四、总结与最佳实践

## 第 2 讲 CPU 缓存与数据局部性
- 摘要：缓存层次、缓存行、伪共享、AoS 与 SoA
- 阶段：核心机制
- 能力点：能根据访问模式选择内存布局，并定位伪共享
- 前置：第 1 讲
- 难度：进阶
- 时长：50

### 小节
1. 引言：缓存决定性能上限
2. 一、缓存层次与缓存行
3. 二、伪共享与数据布局
4. 三、访问模式与选型
5. 四、总结与最佳实践

## 第 3 讲 并发编程基础
- 摘要：线程模型、互斥锁、原子操作、内存序
- 阶段：核心机制
- 能力点：能写出正确的多线程临界区，并判断何时需要无锁
- 前置：第 1 讲
- 难度：进阶
- 时长：55

### 小节
1. 引言：并发为什么难
2. 一、线程与同步原语
3. 二、原子操作与内存序
4. 三、锁的代价与选型
5. 四、总结与最佳实践

## 第 4 讲 性能剖析实战
- 摘要：perf、火焰图、基准测试、瓶颈定位
- 阶段：工程实战
- 能力点：能用数据证明瓶颈在哪，而不是凭直觉优化
- 前置：第 2、3 讲
- 难度：实战
- 时长：60

### 小节
1. 引言：没有测量就没有优化
2. 一、CPU 剖析：perf 与火焰图
3. 二、内存与锁的剖析
4. 三、基准测试方法与陷阱
5. 四、总结与最佳实践

## 第 5 讲 综合案例：高性能键值存储

- 阶段：综合案例
- 能力点：能把前面讲的技术组合成一个可运行的系统

- 时长：75
